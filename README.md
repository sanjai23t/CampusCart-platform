# CampusCart

## Cloud-Native Smart Campus Marketplace

CampusCart is a microservices-based e-commerce
application designed for the campus marketplace.

## Project Objectives

- Build a scalable microservices application.
- Containerize services using Docker.
- Provision AWS infrastructure using Terraform.
- Deploy applications on Amazon EKS.
- Automate CI/CD using GitHub Actions.
- Implement GitOps using Argo CD.
- Monitor applications using OpenTelemetry,
  Prometheus and Grafana.
- Perform load testing and failure testing.

## Technology Stack

- Git and GitHub
- Docker and Docker Compose
- AWS
- Terraform
- Kubernetes
- GitHub Actions
- GHCR
- Argo CD
- OpenTelemetry
- Prometheus
- Grafana
